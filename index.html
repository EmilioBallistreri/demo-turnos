Bienvenido al Turnero de Peluquería

Seleccioná una opción para abrir la ventana de registro o iniciar sesión con tu DNI. Cada perfil accede a una web exclusiva según su rol.

Opción 1
👤

Registrarme como Cliente

Cargá tus datos personales una única vez para que queden guardados automáticamente cuando pidas un turno en el calendario.

  • ✓ Acceso a la Web exclusiva de Clientes
  • ✓ Datos precargados al solicitar turno
  • ✓ Calendario de días, meses y horas libres/ocupadas
Abrir Registro de Cliente →
Opción 2
✂️

Registrarme como Peluquero

Registrate con tus datos personales y el nombre de la peluquería o peluquerías donde trabajás para gestionar tus turnos.

  • ✓ Acceso a la Web exclusiva de Peluqueros
  • ✓ Turnero con clientes anotados por día y hora
  • ✓ Historial y cambio de estado (Pendiente, Atendido, No atendido)
Abrir Registro de Peluquero →
